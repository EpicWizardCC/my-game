How to Play Offline & Convert to `.exe`

1 Save and Play Offline on Chromebook

Chromebooks do not natively allow executing `.exe` binary files without developer mode or Linux setup. However, HTML files run completely offline inside Chrome!

  1. Right-click anywhere on this page and select Save As... (or press Ctrl + S).
  2. Save the file as dodge-game.html on your Chromebook's local Downloads folder.
  3. Double-click dodge-game.html in the Chromebook Files app anytime—even without Wi-Fi—to launch and play!

2 Converting to a Windows Executable (`.exe`)

If you want to run this game as a native standalone desktop app on a Windows PC without a web browser interface, you can package this HTML file into an `.exe` using one of the following methods on a PC:

Method A: Web2Exe Tools (Quickest)

Use lightweight conversion utilities like HTML Executable or Web2Executable:

  • Download HTML Executable on Windows.
  • Select "HTML Web Site / HTML5 App".
  • Set your entry point to index.html.
  • Click Compile to EXE to generate your portable executable file.

Method B: Electron / NW.js (Developer Standard)

Package the web code into a modern desktop app shell:

  • Install Node.js on a computer.
  • Use nativefier via terminal:
    npx nativefier --name "DodgeGame" "path/to/dodge-game.html"
  • It outputs a desktop folder containing your runnable DodgeGame.exe.
